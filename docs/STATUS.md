# TextComb 当前状态

> 最后更新：2026-07-24
>
> 本文件是面向新主机和新 Codex 会话的快速上下文，不替代 GitHub Issues 的详细任务记录。完成一项具体工作后，应更新对应 Issue/PR；只有阶段、阻塞或方向变化时才更新本文件。

## 当前阶段

- 阶段：开源 MVP 基线，进入质量加固和协作准备。
- 代码状态：仓库已具备可部署的 MVP 基线，`main` 为共享稳定分支。
- 质量状态：尚未对外声明参考模型达到 90% / 90% / 70% 门槛；私有评测集和连续评测仍是发布前条件。
- 商业化状态：未开始，按路线图后置。
- 小程序状态：未开始，等待 Web 和商业流程稳定。

## 已具备

- Rust API、Worker、管理 CLI、共享领域和核心库。
- Vue 3 工作台、登录、管理员用户、BYOK OpenAI 兼容模型配置。
- TXT、DOCX、文字型 PDF 解析和来源定位；扫描版 PDF 直接拒绝。
- PostgreSQL 任务队列、租约恢复、异步进度、取消和失败块重试。
- 双轮 AI 候选/复核、问题分层、位置校验、去重和 ReportV1。
- 在线报告、JSON、Markdown、PDF 导出和逐条反馈。
- Docker Compose、开发文档、假模型、评测工具、测试样例和负载脚本。
- 仓库根目录 `AGENTS.md`，用于不同主机上的 Codex 共享开发规则。

## 当前优先事项

1. 建立私有标注评测集和可重复的准确率/召回率报告。
2. 补齐三类输入、位置映射、长文切块、模型输出修复和重叠去重的回归测试。
3. 验证 5 万字文章的取消、失败重试、超时、清理和报告完整性。
4. 完成 10 个并发任务的假模型负载测试和 Worker 租约故障恢复测试。
5. 完善 CI、部署、备份、监控、Issue/PR 模板和外部贡献文档。

## 当前阻塞与待决策

- 参考模型、提示词和依据库版本需要维护者锁定后才能进行正式质量声明。
- 私有评测文章、标注人员和第三人裁决流程尚未公开，不能提交到仓库。
- 商业价格、支付、公开注册和小程序不属于当前阶段，暂不创建实现任务。
- 如果新任务与 `PROJECT.md` 或 `ROADMAP.md` 的首版边界冲突，应先创建决策 Issue，不要直接扩大范围。
