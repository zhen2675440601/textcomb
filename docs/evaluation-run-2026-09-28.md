# 2026-09-28 探索性评测与端到端校验

此记录用于复现本轮修正的行为，不属于发布质量认证。文章全文、模型密钥和用户数据均未写入仓库。

## 真实文章试跑

- 来源：[中国科学院沈阳应用生态研究所《颠覆传统植物生存逻辑丨赤箭——天麻》](https://www.iae.cas.cn/smy/kpjy/kpzs/202504/t20250429_7619917.html)，取正文中介绍共生、生长周期和人工栽培的三个自然段，共 393 个字符。
- 模型：本地已配置的 `deepseek-flash`，OpenAI Compatible 协议。该模型配置未通过私有评测认证。
- 对照：原文节选和同文植入四处确定性错误的副本。四处分别为重复句号、同音错字、缺主语的“通过……使……”句式、冲突的关联词。没有把修改版当作真实文章的原貌。
- `zh-cn-proofread-v6`：原文节选报告 0 项；植入版定位 4/4，分类正确 2/4。错字被归为搭配不当，关联词冲突被归为成分赘余。
- `zh-cn-proofread-v7`：原文节选报告 0 项；植入版定位 4/4，四处分类均与植入标签一致，报告均为正式问题。

这些数字只描述一个节选和四处人工植入错误。原文未经过双人逐字标注，因而“报告 0 项”不能证明没有漏报；也不能据此计算或宣称总体准确率、召回率达到发布门槛。错字报告位置有时包含整个固定短语，私有 Gold 集需统一标注范围，避免将范围口径差异误算为识别失败。

本轮真实文章试跑使用粘贴正文入口。PDF 逐页拒绝逻辑通过单元测试验证；尚需收集带空白页、整页图表和混合扫描页的可再分发样本，检验误拒与漏拒。

## 功能和负载校验

- 通过 API 创建任务并读取在线报告，提取原文窗口与提交正文一致，字符位置可回到原文。
- 作者将一条问题标记为“正确”后，JSON、Markdown 和 PDF 导出均包含审核状态；暂时添加的漏检反馈也出现在三种导出中，随后已删除该测试反馈。
- PDF 下载最初暴露 API 镜像缺少 Typst 的问题；补齐 Typst 和中文字体后返回 200，生成约 76 KiB PDF，并从 PDF 文字中核对到审核和漏检内容。
- 假模型完成单篇 200,000 字分析，末尾问题定位在接近文末的字符范围；10 篇各 50,000 字任务均完成、报告 ID 各不相同，只有含已知问题的文章产生问题。加入 1 秒模型延迟后再次运行 10 篇，数据库时间戳显示峰值同时运行 10 个任务。
- 故障注入发现分块进入复核时的数据库事务可能长时间占锁，使心跳和失败状态停滞。改为单条原子更新并重跑：模型中断后任务进入 `failed`，保留 1/68 已完成块；模型恢复后重试完成 68/68。共记录 69 次成功候选调用，其中包含失败前已调用但未完成的块。
- 运行中取消 200,000 字任务后，任务进入 `cancelled`，完整提取正文和分块内容均清空；假模型请求数在取消后复查保持 2 次不变。
- 额外创建一份只访问本机不存在端口的失败任务，确认失败后正文先按重试窗口保留；只将该测试文档的到期时间调到过去并触发清理后，提取正文、原文件路径、到期标记和分块内容全部清空。
- 23 个假模型测试任务及额外的清理测试任务、两份临时模型配置和临时容器均已清理；临时管理员测试会话已撤销。真实文章的四份测试报告暂留本地供维护者查看。

## 后续质量门槛

发布质量声明仍须按 [评测规程](evaluation.md) 建立不少于 50 篇双人标注、第三人裁决的私有文章集，覆盖自媒体、论文和财报场景；锁定模型、提示词和分析器版本后连续两轮达到 90% / 90% / 70%。本次试跑不替代该流程。
