# 商业版与小程序边界

本文件只记录扩展边界，不代表开源 MVP 已实现收费能力。

商业托管版计划增加公开注册、邮件找回、服务端模型额度、不可变积分账本和微信支付。对用户仍展示“按篇付费”，内部按 `ceil(正文字符数 / 5000)` 冻结 1–10 个分析单位；成功结算，失败或取消返还，主动重新分析视为新任务。人民币价格必须基于真实两轮模型、重试、存储、支付和运营成本采样，当前不写死。

支付、积分和订单状态必须由 Rust 服务端维护，使用支付服务端通知完成最终确认，客户端返回页不能作为到账依据。商业上线前需要隐私政策、服务条款、第三方模型披露、支付和数据处理专项法律审查。

微信小程序在 Web 付费流程稳定后开始，使用 uni-app Vue 3＋TypeScript，共享 OpenAPI 客户端与领域类型，不共享复杂 Web 组件。它只调用现有 API，支持微信登录绑定、上传、进度、报告、逐条反馈与支付；继续不提供全文在线编辑。
